**门禁逼出的三个真问题（都修了）**：① **空闲成员被误清扫**——只靠 commit 说话，没有提交时不发任何请求，
3s 后按静默离开 → 补上显式心跳（这正是该命令存在的理由）；② **成员被 kill 时输出丢失**——重定向的 stdout 是
块缓冲，`--follow` 成员被终止时已读记录全丢 → `print_entry` 每条 flush；③ 门禁自身的断言从"某个瞬间的快照"
改成"等稳定"（再平衡窗口内重叠是**允许**的语义，快照会把它误判为违规）。
