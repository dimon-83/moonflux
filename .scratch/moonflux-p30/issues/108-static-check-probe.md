# T108 · 表达式静态检查探针（发布期不再用一个字面量断言输入）

**What to build**: 把 `apps/transform` 的发布期探针从"`value = "a"`"改为**两个由表达式自己命名的形状**：抽出表达式里 JSON 安全的字符串字面量，构造 `{"k":"k"}` 与 `{"k":1}`，任一求值成立即允许发布；两个都不成立才报错（报第一个形状的错误）。

**Why**: 探针是对输入的一个断言——`"a"` 等于宣称"记录不是 JSON"，于是 `fromJSON(value)` 在任何记录流动前被拒。**能力一直在，拦住它的是我们自己的检查**。也不能简单删掉检查：未知名与类型错误的拦截就靠这一步。

**Blocked by**: 无。
